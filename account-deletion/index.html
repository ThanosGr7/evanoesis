Delete Your Code Evryma Account

You can permanently delete your Code Evryma account and associated personal data.

Delete inside the app

The fastest way is directly inside Code Evryma:

Settings → Account → Delete Account Forever

Delete from the website

Enter the same Code Evryma username and password you use in the app.

What is deleted

Your sign-in account, username, account settings, profile notes/media, private findings, scan history, map pins, private location records, and linked AI memory where applicable.

Limited records may be retained where required or permitted by law. Backups may remain temporarily according to the applicable backup cycle.
